# Fonts

Self-hosted so the site has no third-party request, renders identically offline
under `pellet web`, and does not flash unstyled text on first paint.

| File | Family | Licence |
| --- | --- | --- |
| `jetbrains-mono-400.woff2` | JetBrains Mono Regular | SIL Open Font License 1.1 — `JetBrainsMono-OFL.txt` |
| `jetbrains-mono-500.woff2` | JetBrains Mono Bold, served as weight 500 | same |
| `pixelify-sans-400.woff2` | Pixelify Sans Medium | SIL Open Font License 1.1 — `PixelifySans-OFL.txt` |

Both families are subset. JetBrains Mono keeps Latin plus the box-drawing and
block characters the terminal panes use. Pixelify Sans is wordmark-only:
alphanumerics and basic punctuation, which is why it is 5 KB.
